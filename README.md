## ✨ QuiCraft って？

**QuiCraft（くいっくらふと）** は、Java版 Minecraft のサーバーを **GUI で設定するだけで自動生成** できる Windows アプリです。

通常、Minecraft サーバーを建てるには `server.jar` のダウンロード、`eula.txt` の同意、`server.properties` の編集、起動スクリプトの作成…と多くの手順が必要です。  
QuiCraft なら、**画面上で必要な項目を入力して「実行」ボタンを押すだけ** で、すぐにサーバーを起動できる状態が整います。

## 🚀 できること

| 機能 | 説明 |
|:--|:--|
| 🎮 **バージョン選択** | 1.2.1 ～ 26.2 まで、幅広いバージョンに対応 |
| ⚡ **ワンクリック生成** | サーバー jar のダウンロードから設定ファイル作成まで全自動 |
| 🔧 **サーバー設定** | ゲームモード / 難易度 / 最大人数 / ポート / 描画距離 / MOTD など |
| 🎨 **サーバーアイコン** | お好きな 64×64 の PNG 画像を設定可能 |
| 🌍 **既存ワールド読み込み** | 既存のワールドフォルダを指定してサーバーに組み込み |
| 💾 **メモリ設定** | 最小・最大メモリを自由に設定 |
| 🏔️ **シード値指定** | お気に入りのシード値でワールド生成 |
| ⚔️ **ハードコア / 飛行 / コマンドブロック** | チェックボックスで簡単にON/OFF |

## 📦 ダウンロード & インストール

1. [**Releases ページ**](https://github.com/LEGOLANNDO/QuiCraft/releases/latest) から最新の `QuiCraft.zip` をダウンロード
2. ZIP を好きな場所に **展開（解凍）**
3. フォルダ内の **`QuiCraft.exe`** をダブルクリックで起動！

> **📌 ポイント:** .NET ランタイムのインストールは不要です（アプリに同梱済み）

## 📖 使い方

### Step 1 ― 基本設定を入力

| 項目 | 説明 | 例 |
|:--|:--|:--|
| **プロジェクト名** | サーバーフォルダの名前（必須） | `MyServer` |
| **サーバーバージョン** | ドロップダウンからバージョンを選択（必須） | `1.21.11` |
| **最小メモリ(GB)** | JVM に割り当てる最小メモリ | `2` |
| **最大メモリ(GB)** | JVM に割り当てる最大メモリ | `4` |

### Step 2 ― お好みで任意設定

- **サーバーアイコン** ― 64×64 の PNG を「選択...」ボタンから指定
- **既存ワールドフォルダ** ― 使いたいワールドがあれば「選択...」ボタンから指定

### Step 3 ― サーバープロパティを設定

ゲームモード、難易度、最大人数、ポート番号、描画距離、シード値、MOTD などをお好みに設定します。  
特に変更しなくてもデフォルト値で動作します。

### Step 4 ― EULA に同意して実行！

1. 画面下部の **「Minecraft EULA に同意しますか？」** にチェック ✅
2. **「実行」** ボタンをクリック
3. プログレスバーが 100% になったら完了 🎉

### Step 5 ― サーバーを起動

生成された **プロジェクト名フォルダ** の中にある **`run.bat`** をダブルクリックすれば、サーバーが起動します！

## 🛠️ 動作環境

- **OS:** Windows 10 / 11（64bit）
- **Java:** サーバーの実行に Java が必要です（[Adoptium](https://adoptium.net/) などからインストール）
- **ネットワーク:** 初回起動時にバージョン情報の取得とサーバー jar のダウンロードにインターネット接続が必要です
